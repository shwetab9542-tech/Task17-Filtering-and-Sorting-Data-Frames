Task17- Filtering and Sorting DataFrames

## Task Overview

This project demonstrates how to filter rows and sort data in a DataFrame using Python and Pandas.

## Objective

To learn fundamental techniques for retrieving specific records from a dataset and arranging DataFrame values in ascending and descending order.

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Dataset

*Titanic Dataset*

## Key Concepts

- Boolean conditions
- DataFrame filtering
- Multiple conditions using &
- sort_values()
- Ascending and descending sorting

## Analysis

Filtering helps identify specific groups of passengers based on different conditions.
 Sorting makes it easier to organize and analyze records according to values such as age, fare, and passenger class.

## Conclusion

This task provides practical experience with Pandas DataFrames and demonstrates how
 filtering and sorting can be used to retrieve and organize useful information from a dataset.
